Canceled Codebase

A collaborative code editor rendered on an OffscreenCanvas, with host-project cloning and mini-git. The full editor UI only appears inside the Perchance editor — this page is the plugin's public front.

  1. In your generator's main.pjs lists panel, add:
    canvasEditor = \{import:generator\}
  2. In your page code:
    const api = await root.canvasEditor;
const \{ win, editor \} = await api.createEditorWindow(\{ text: "console.log(1)" \});
  3. Clone any host project into versioned history:
    const \{ panel, repo \} = await api.createProjectWindow(\{\});
