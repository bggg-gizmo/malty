Oracle freeze — deliberate change vs regression

Freeze the contract JSON beside the commit it was checked against. On a later refactor, recheck: identical reads STABLE; changed-with-a-written-reason reads CLAIMED (evolution, old version kept); changed-without-reason reads UNCLAIMED — regression until an author claims it in writing.

Commit recipe — for infra providers

One named change plus one acceptance check. To commit infra: (1) list the live endpoint on the Net tab (Relay, Hosts, or MCP card) so anyone can test it from their browser; (2) add the row here and advance it to committed; (3) mirror it on a webmesh deed pointing at your surface.
