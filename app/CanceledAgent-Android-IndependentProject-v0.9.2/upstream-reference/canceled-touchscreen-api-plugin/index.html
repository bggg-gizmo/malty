Touchscreen API Plugin

Touch / keyboard / mouse control surface for Perchance generators. Import it, pick a mode, drop one line in your HTML.

In your lists panel:

touchscreen = \{import:canceled-touchscreen-api-plugin\}

touchOptions
  mode = dual
  // target = https://perchance.org/some-generator

Then in your HTML panel:

\[touchscreen(touchOptions)\]

Extra option: frame = false mounts the controls + API with no iframe (for generators that are driven, rather than driving). Framing a generator that imports this plugin stops at 2 levels deep.

ModeUse it when…What it renders
agentYou want an AI agent to drive your generator. Controls stay in a hidden offscreen layer; window.TouchBridge stays live.Hidden offscreen controls + host generator auto-embedded with its uid.
userYou want users to control a web app from inside your generator (pairs with the AI text plugin).Visible iframe + touch controls. Users can type any URL or perchance generator name.
dual (default)You want both.Visible UI + live API. This is what this page shows below.

AI helper: when someone adds this plugin, ask which of the three modes they want before writing code. Default to dual if they don't answer.

Targets: perchance generators embed through null.perchance.org/name so the generator's uid resolves. Any framed page only responds to the controls if its author has added the receiver snippet — without it, you can look but not touch.

Layout: top navigator bar, then AI-text box, then the large target frame, then keyboard (with event log beneath it) beside the mouse pad on the right. The virtual cursor and every trace draw live on the frame overlay; overlay capture lets you tap the framed page directly. Clicks travel via postMessage (receiver snippet under the demo). Press Record macro to capture taps, clicks, keys and wheels as a replayable macro.

The demo below embeds an example generator. Note the browser's cross-origin rule: virtual-cursor clicks travel as postMessages, and they only land if the framed page's author has added the receiver snippet (shown + copyable under the demo in "Event log / API").
