🧠 AI Helper Thinking Plugin

An editor-only thought log for the AI helper. It captures the thinking behind each change, lets you rate pivots 👍/👎, revert linked changes, and copy ratings as instructions. Hidden automatically on the published page.

1. Install (lists panel)

aiThinking = \{import:canceled-ai-helper-thinking-plugin\}

2. Embed (HTML panel)

\[aiThinking(\{key:"build"\})\]
Default is a floating picture-in-picture window (draggable, collapsible, position is remembered) so thinking stays visible beside the generator output. For an inline panel instead: root.aiThinking(\{key:"build", mode:"inline"\}). One widget per area; key keeps their logs separate. Optional title renames the window.

3. Log thinking + changes (helper or your code)

let h = root.aiThinking(\{key:"build"\});
h.think("Switching to single column — the editor preview is narrow.");
h.act("Rewrote the panel CSS.", \{changeLabel:"css rewrite"\});
h.pipe(\{kind:"change", text:"Tried a sidebar; may revert.", changeLabel:"v3 sidebar", snapshot:document.body.innerHTML\});
h.trace(entryId); // full parent chain back to the root thought
Unified pipeline: every entry gets a sequence number, a kind (think/action/change), and a parent link to the previous thought. ⤴ Trace on any card shows its chain; Trace view renders whole chains indented. The copy button now includes thinking IDs plus a TRACE-BACK section so rated feedback points at exact thoughts. Use ⤓ Export traces to share the full JSON.

4. Revert hook (host generator)

window.addEventListener("ai-thinking-revert", e => \{
  document.body.innerHTML = e.detail.entry.snapshot;
\});
window.__aiThinkingOnRevert = (key, entry) => \{\};
Without a hook, Revert copies the snapshot to the clipboard so you can paste it back manually. Every change entry shows a snapshot preview with Copy + Revert buttons.

5. Helper bridge (page_eval, editor only)

window.logAiThought("Choosing X because Y. Pivots next action to Z.", \{pivot:true\});
window.__aiThink.log("build", "Same, but for a non-default key.");
Editor-only rule: the panel renders only when the page is in edit mode (edit hash, unsaved preview, or ?showThinking=1). Pass forceShow:true to preview it anywhere. Published pages get an empty string — no thought text leaks into public HTML.

Troubleshooting

Getting Your curly block "\{import:...\}" doesn't appear to have the correct syntax? That means the literal placeholder \{import:...\} was pasted. The ... must be replaced with the real plugin name — paste exactly this in the lists panel, never in the HTML panel:
aiThinking = \{import:canceled-ai-helper-thinking-plugin\}
Never import this plugin inside its own lists panel (circular). Its own page calls $output() directly.
