## Add your contribution

Every pull request accepted into the official Malty project must append the contributor's chosen public name or handle and an accurate description of their work in this file. Preserve the earlier entries.

Fork maintainers are encouraged to continue the chain. All redistributors must preserve applicable attribution notices as required by the Apache License 2.0 and the included NOTICE file. Apache-2.0 does not require an independent fork author to add a self-credit row; adding that row is an official project contribution policy.
